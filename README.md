# ☀️ Güneş Mobilya — Muhasebe

Az teknoloji bilgisiyle kullanılabilecek, sade bir kasa ve veresiye defteri.

## Nasıl açılır?
`index.html` dosyasını telefonda veya bilgisayarda tarayıcıyla açmanız yeterli. İnternet gerekmez.

## Neler yapılabilir?
- **Para Girdi** (yeşil buton): Satış, peşinat, tahsilat
- **Para Çıktı** (kırmızı buton): Malzeme, kira, maaş, elektrik/su, nakliye…
- **Veresiye Defteri**: Müşteri ekleme, veresiye satış (peşinatla birlikte), ödeme alma, kalan borç
- **Kayıtlar**: Ay ay tüm kayıtlar, gün gün toplam, kayıt silme
- **Rapor**: Ayın giren/çıkan parası, elde kalan, paranın nereye gittiği
- **Yedek** (⚙️): Yedek dosyası indirme ve geri yükleme

## Önemli
Bilgiler o cihazın tarayıcısında saklanır. **Haftada bir yedek alın.** Uygulama 7 gün yedek alınmazsa uyarır.
